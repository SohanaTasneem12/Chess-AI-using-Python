# Chess-AI-using-Python

A **Python-based Chess AI** developed using **Minimax Algorithm with Alpha-Beta Pruning**. This project is inspired by Eddie Sharpe’s YouTube playlist but includes additional functionalities and improvements implemented by me.  

## **Features Implemented:**  
✅ Basic Chess Engine with Move Validation  
✅ Minimax Algorithm with Alpha-Beta Pruning for AI decision-making  
✅ GUI-based board interaction  

## **Future Enhancements:**  
🚀 **Game Mode Selection** – Choose between AI vs Human and Human vs Human modes  
♟️ **Flip Board Feature** – View from Black’s perspective  
⚡ **Move Ordering** – Optimize AI search by prioritizing high-value moves  
🧠 **AI Adaptive Learning** – AI will analyze past games and refine its strategy dynamically
